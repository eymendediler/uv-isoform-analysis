# Reproducibility commands

This page records the exact command sequence for the accepted analysis. Run all
commands from the repository root. The single-command wrapper executes the same
sequence and stops immediately if any step fails.

## Create the versioned environment

```bash
conda env create --prefix .envs/dtu -f environment-dtu.yml
```

## Run the complete accepted workflow

```bash
bash scripts/run_current_analysis.sh .envs/dtu
```

## Expanded command sequence

```bash
python scripts/audit_salmon_inputs.py
python scripts/export_gencode_annotation.py

conda run --prefix .envs/dtu Rscript scripts/run_drimseq_omnibus.R \
  --filter loose --model unblocked --input-scale scaled_tpm \
  --alpha 0.05 --threads 1
conda run --prefix .envs/dtu Rscript scripts/run_drimseq_omnibus.R \
  --filter medium --model unblocked --input-scale scaled_tpm \
  --alpha 0.05 --threads 1
conda run --prefix .envs/dtu Rscript scripts/run_drimseq_omnibus.R \
  --filter strict --model unblocked --input-scale scaled_tpm \
  --alpha 0.05 --threads 1

conda run --prefix .envs/dtu Rscript \
  scripts/apply_drimseq_proportion_sd_filter.R
python scripts/summarize_dtu_sensitivity.py \
  --input-scale scaled_tpm --prop-sd-filter
python scripts/validate_protein_sequences.py \
  --input-scale scaled_tpm --prop-sd-filter
conda run --prefix .envs/dtu Rscript \
  scripts/run_gene_expression_timecourse.R
python scripts/summarize_biological_evidence.py
conda run --prefix .envs/dtu Rscript \
  scripts/run_drimseq_timepoint_contrasts.R
python scripts/plot_primary_dtu_statistics.py
```

## Accepted output locations

- `results/qc/`: Salmon input audit and sample-level quality summaries.
- `results/dtu_v2/{loose,medium,strict}_unblocked_scaled_tpm/`: independent
  information-filter runs, design matrices, omnibus tests and corrected stageR
  tables. Binary fitted-model objects are deliberately not versioned because
  they are platform-dependent and regenerated by the commands above.
- `results/dtu_v2/robust_stageR_transcripts_all_filters_scaled_tpm_prop_sd_0_1.tsv.gz`:
  the three-filter robust transcript intersection.
- `results/dtu_v2/robust_protein_sequence_details_scaled_tpm_prop_sd_0_1.tsv.gz`:
  robust coding transcripts with protein-sequence verification.
- `results/dtu_v2/timepoint_contrasts_strict_scaled_tpm_prop_sd_0_1.tsv.gz`:
  all secondary transcript-by-time tests with global BH correction.
- `results/dtu_v2/primary_candidate_timepoint_statistics/`: presentation
  figures and the exact replicate-level plotting source data.
- `results/gene_expression_time/`: complementary gene-level DESeq2 time test.

## Deliberately excluded generated files

`drimseq_fit.rds` files, local software environments and cache files are not
stored in Git. The RDS objects are version- and platform-dependent binary model
objects rather than independent source data. They are recreated by
`run_drimseq_omnibus.R`; all accepted tabular results derived from them are
versioned. Superseded exploratory results remain clearly separated from the
accepted workflow as described in `LEGACY_ANALYSES.md`.
